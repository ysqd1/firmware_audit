## Agent Brief

**Summary:** 在恢复入口拒绝领域非法但事件与快照一致的状态，并统一磁盘损坏异常。

**Current behavior:** Analysis 恢复只验证结构/身份，可能接受 queued 与 confirmed 并存；Verification 恢复未核验已有 Claim Result 的引用是否属于本次独立 Evidence，可能在收尾时生成缺乏有效引用的 Finding。Candidate Store 读取损坏 source/proposal_id 时泄漏 CandidateIntakeError；Evidence schema 错误又被重复包装成恢复错误。

**已核实的触发条件：** 以合法案卷跑一轮复核后中断，通过 InvestigationStore.save 写入与事件一致、但引用 ev-999999 的全 supported Claim Results；恢复后提交空 delta 的 complete_verification，当前可得到 confirmed/f-0001。类似地，写入 queued/confirmed/completed 投影会被 Analysis 接受。该复现刻意绕过正常输入校验；未发现正常动作能产生这种非法历史，不将它描述为普通断电必现问题。

**Desired behavior:** 恢复只接受符合当前领域契约的投影；非法状态在继续模型请求、工具执行或生成 Finding 前以 StoreError 拒绝，保留原始工件供检查。正常恢复、工具重放和 D2 的预算收束语义保持可用。

**Key interfaces:** HostAnalysisTracer 的恢复入口、HostVerificationRunner 的会话恢复与结果恢复入口、InvestigationStore、CandidateStore、EvidenceRecorder；复用已有生命周期和 Claim Result 策略，覆盖恢复入口，不全面改造 runtime 建模。

# 06: 单次执行会话 tracer

**What to build:** 会话制最小完整链路一次打穿：开启会话（按声明干净重建运行目录）→ 执行一次目标程序（QEMU、单次 60 秒默认 / 180 秒硬上限）→ 停机封存。落地即可演示一次性实验：Observation 回到 Agent、结果分类落盘、会话台账 v1（单条执行记录 + digest）、会话计数进预算（Analysis / Verification 各最多 3 个会话）、Evidence 写入。子进程链、多执行、适配模板都不在本票。

**Blocked by:** 15

**Status:** wontfix

**Superseded by:** [16](16-single-execution-chain.md)

> 已合并，不再单独执行；wontfix 仅表示本旧票停止调度，不表示取消需求或已实现。原正文、AC 和依赖保留为历史，现行要求以替代票为准。

本票采用票 15 已验收的 PRoot + QEMU 后端；“子进程链不在本票”仅指完整业务链验收移交 09，不能延后运行时隔离、子孙进程清理。tracer 在本票标题中指最小端到端贯通，不等于已实现完整 syscall 追踪。

- [ ] Host 会话入口实际调用受约束的 PRoot 后端；每次执行独立 PRoot，版本、原固件与装载桩身份分别记录
- [ ] 票 15 的绕过拒绝与只读边界在正式工具入口仍成立；超时清理覆盖 PRoot/QEMU/子孙进程，不能只停止 Docker 客户端
- [ ] 核实 QEMU `-strace` 在 PRoot 下的可用性和输出限制；若使用只作为辅助日志，不将其默认视为完整进程台账或隔离机制

- [ ] 端到端演示：真实固件单发程序（ARM32 小端）在会话内执行，Observation 返回，台账与证据工件落盘于本世代工件区
- [ ] 干净重建：会话运行目录从原始输入与声明材料构建，原固件解包树只读且不被修改
- [ ] 单次执行超时生效，超时触发容器与派生进程清理，"清理不确定"可表达且不伪装为正常结果
- [ ] 会话计数进预算：同角色第 4 个会话被拒且错误可读；预检不占会话名额但计入工具调用
- [ ] 结果分类可用（本票至少覆盖正常退出/非零退出/目标信号/超时/执行设施失败五类）
- [ ] 离线替身测试 + 真实执行门控测试；全量套件绿

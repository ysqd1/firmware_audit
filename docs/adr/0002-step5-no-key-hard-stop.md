# 0002-Step5 无 API key 时立即终止,不降级纯规则

Step5 在无 API key 或 API 调用失败时抛 `LLMError` 立即终止,不产出降级工件、不执行规则模式(`run_step5.py`)。早期设计(`requirements.md:30/118/126`、`rules.md:6`)是无 key 降级纯规则、仍出报告,但该路径从未在 Step5 落地,代码里不存在规则模式回退——Step1-4 的规则化处理才是"无 LLM"的部分。

选择硬终止而非降级,是因为降级纯规则报告会给出无置信度的"假确定性",且当时已决定 LLM 编排是唯一可信的审计引擎;留下一个没有 LLM 能力的编排层没有意义。用户可保留 `target/<N>/process/` 内已产出的 Step1-4 产物,配置好 key 后重跑 Step5。

文档里的"降级纯规则仍出报告"是旧设计的残留,与代码不一致,应以本 ADR 与 `run_step5.py` 为准。
